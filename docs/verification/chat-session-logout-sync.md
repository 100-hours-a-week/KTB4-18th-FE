# F5 인증 종료에 따른 채팅 정리

## 담당 범위

채팅 연결의 WebSocket 4100 / CHAT_LOGGED_OUT 사유를 표시하고 전송·자동 재연결을 중단한다.
기존 AUTH_EXPIRED_EVENT / ACCESS_TOKEN_CHANGED_EVENT에 따른 참여·화면 메시지 정리 흐름을 검증한다.
같은 sid의 토큰 갱신에서는 기존 참여를 유지한다.

인증 서비스·logout API·BroadcastChannel/storage 동기화·토큰 저장 코드의 미커밋 수정은 원복했다.
서버 종료 프레임만 보고 채팅에서 인증 토큰을 지우지 않는다.
인증 담당자가 각 탭의 토큰과 로그인 상태를 변경하고 기존 이벤트로 통지해야 한다.
해당 모듈의 기존 캐시 정리 호출도 유지하며 새 인증 동기화 정책을 채팅 코드에 추가하지 않는다.

## 검증

- 채팅 관련 Vitest 96개 중 93개 통과 / 실제 서버 조건부 3개 제외, 실패 0.
- 전체 Vitest 595개 중 590개 통과 / 기존 이미지 추천 dialog 기대값 1개 실패 / 조건부 4개 제외.
- ESLint, TypeScript/Vite build, 변경 파일 Prettier 통과. 기존 500kB 번들 경고 유지.
- 전체 Prettier는 기존 인증 6개 파일 위반으로 실패. 해당 인증 파일은 수정하지 않았다.
- 결과 JSON: node_modules/.tmp/f5-chat-focused.json 및 f5-chat-unit.json.
- 실제 브라우저·물리 기기·운영 로그인 쿠키 검증은 이번에 수행하지 않았다.
- 기능 40acbd3 / 검증 8b87e19. 인증 담당자의 동기화 구현은 완료 범위에 포함하지 않는다.
연결 종료 이후 전송·재연결·늦은 메시지 차단, 인증 제거/만료 시 Hook 정리,
기존 복구·토큰 갱신·계정/세션 전환 회귀를 검증한다.
실제 로그아웃 API·같은 브라우저 두 탭 전파·다른 물리 기기 유지는 인증 담당자 연동 후 공동 검증한다.
이번 검증을 그 통합 검증 완료로 표시하지 않는다.

## 연동·적용

BE의 ChatSessionLogoutEvent 처리와 인증 담당자의 세션별 이벤트 발행을 함께 적용해야 한다.
그 전에는 새 로그아웃 API의 동작 완료를 보장하지 않는다.
공개 REST 요청·응답, 환경 변수, 의존성·브라우저 runner, DB 변경은 없다.
기존 브라우저 E2E 환경은 변경하지 않았다.
롤백 시 일반 4100 종료 안내로 되돌아가며 인증 담당자의 동기화 코드는 별도 관리한다.
