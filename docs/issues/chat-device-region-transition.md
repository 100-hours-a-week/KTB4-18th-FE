# [FE][TASK] 기기별 지역 이동 연동

## 목적과 범위

- 현재 브라우저 인증 세션의 GPS 판정과 채팅 이동 요청을 같은 세션에 고정한다.
- 10분 주기·15초 재확인·경계 오차/판정 실패 시 기존 방 유지 정책을 보존한다.
- 인증 변경·화면 이탈·지연된 위치/입장 응답이 다른 세션에 입장·퇴장을 요청하지 않도록 차단한다.
- 동일 sid 토큰 갱신은 유지하고 다른 기기로 지역 이동 상태를 전파하지 않는다.
- 탭별 퇴장·로그아웃·과거 이력 공유 및 음악 기능은 제외한다.

## 계약과 의존성

- 선행 F1과 BE B4 이후 BE B5와 연동한다. 새 JSON 필드나 기기 ID는 추가하지 않는다.
- 실제 GitHub 이슈 번호는 확인 후 연결한다.
