# [FE][TASK] 다중 기기 대화 복원 E2E 검증

## 상위 [FE][FEATURE] 이슈

지역 채팅 다중 탭·기기 정책 개선의 F7 검증 작업이다. 실제 부모·작업 이슈 번호, 담당자, 예상 시간, PR은 등록 시 연결한다.

## 작업 범위

- 독립 브라우저 컨텍스트와 같은 계정의 서로 다른 sid를 사용한 실제 서버 E2E
- 빈 캐시의 서버 이력 복원, 모든 기기 부재 중 메시지 제외, 다른 계정의 이력 격리
- 기기 하나의 퇴장·일시 단절 후 다른 기기의 대화 유지
- 복원 중 실시간 메시지 병합, 조회 실패 후 수동 재시도
- 데스크톱·모바일 viewport에서 실제 채팅 화면과 접근성 이름으로 조작
- 제품 인증 정책·로그인/로그아웃 API·공동 재생·API/DB 변경은 제외

## 화면 / 상태 / 연동 영향

실제 ChatEntryPage·Hook·API·STOMP를 기존 격리 JVM/MySQL에 연결한다. 정상·로딩·실패·재시도 상태를 확인한다. 합성 JWT와 위치를 사용하며 물리 기기·GPS·운영 쿠키 검증으로 간주하지 않는다.

## 완료 조건

- [x] 서로 다른 sid와 독립 저장소를 사용하는 두 기기가 동일 계정의 이력을 복원한다.
- [x] 계정이 모든 기기에서 부재한 동안의 메시지와 다른 계정의 과거 이력을 표시하지 않는다.
- [x] 한 기기의 퇴장·단절에도 다른 기기는 전송할 수 있고 복구 메시지는 한 번만 표시한다.
- [x] 이력 응답 대기 중 전송 차단, 실시간 병합, 실패 후 수동 재시도를 확인한다.
- [x] 데스크톱·모바일 viewport 검증 결과와 실제 기기 미검증 범위를 기록한다.

B1~B10/F1~F6가 선행한다. B7 인증 담당자의 이벤트 발행 의존성은 유지한다. F4의 격리 브라우저 환경을 재사용하며 인증 정보는 임시 fixture에만 보관하고 종료 시 삭제한다. 제품 src 변경 없이 테스트·환경·문서를 목적별 커밋으로 나눈다.
