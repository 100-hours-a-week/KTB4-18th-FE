# [FE][TASK] 다중 탭 퇴장 E2E 검증

## 목적

같은 인증 세션의 여러 브라우저 탭에서 한 탭의 퇴장으로 다른 탭의 채팅이 종료되지 않는지 실제 브라우저·HTTP·WebSocket으로 확인한다.

## 사용자 시나리오

- 한 탭에서 다른 메뉴로 이동·탭 닫기·새로고침을 해도 남은 탭은 전송을 계속한다.
- 퇴장 뒤 재입장하면 새 열람 식별자를 사용하고 부재 중 메시지는 표시하지 않는다.
- 일시 단절은 같은 view로 복구하고 명시적 퇴장과 구분한다.
- 입장 응답 대기 중 화면을 떠나도 그 탭만 정리한다.

## 범위

- 포함: 반복 실행 가능한 브라우저 E2E 환경, 실제 채팅 화면·Hook·API·STOMP 연동, 데스크톱 및 모바일 viewport, 종료 view 권한 거절과 방별 계정 인원 확인, 실행·결과 문서.
- 제외: 로그인 화면·운영 쿠키 인증 검증, 물리 기기·GPS 정확도, B7 로그아웃, 계정 이력 통합, 공동 재생.
- 기존 BE 선택적 browser fixture를 이용하고 BE 제품·스키마·API는 수정하지 않는다.
