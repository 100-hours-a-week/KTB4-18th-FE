# [FE][TASK] 로그아웃 상태에 따른 채팅 연결 정리

## 상위 [FE][FEATURE] 이슈

- 상위 이슈: 기존 지역별 채팅 다중 탭·기기 정책 개선 이슈에 연결
- 맡는 결과: 인증이 종료된 탭의 채팅 연결과 화면을 정리하고 자동 복구를 중단한다.

## 작업 범위

- 포함: 기존 인증 상태 변경 알림에 따른 채팅 정리, 서버의 로그아웃 종료 사유 표시, 전송·자동 재연결 중단, 늦은 복구 결과 제외.
- 제외: 로그아웃 API 호출 변경, 토큰·쿠키 폐기, BroadcastChannel·storage를 통한 탭 간 인증 동기화, 인증 상태 관리 개선.

## 화면 / 상태 / 연동 영향

- 대상: 지역 채팅 화면의 연결·복구·전송 상태.
- 상태: 인증 종료 시 퇴장, 서버 CHAT_LOGGED_OUT 수신 시 로그아웃으로 채팅이 종료되었음을 안내.
- 연동: 인증 담당 모듈이 각 탭에서 기존 ACCESS_TOKEN_CHANGED_EVENT / AUTH_EXPIRED_EVENT 계약으로 상태 변경을 알린다.
- 백엔드: WebSocket 4100 / CHAT_LOGGED_OUT. 인증 토큰을 채팅 모듈에서 임의로 삭제하지 않는다.
- 새 입력·레이아웃·반응형 변경 없음. 기존 연결 상태 안내를 사용한다.

## 완료 조건

- [ ] 인증 상태가 종료되면 채팅 참여와 화면의 이전 메시지가 정리된다.
- [ ] 서버 로그아웃 종료 후 메시지 전송과 자동 재연결을 중단한다.
- [ ] 종료 이후 도착한 메시지·복구 결과를 반영하지 않는다.
- [ ] 같은 sid의 정상 토큰 갱신에서는 채팅을 유지한다.
- [ ] 채팅 모듈에서 토큰을 변경하지 않으며 관련 단위·연동 테스트 결과를 남긴다.

## 의존성 및 결정 필요 사항

- 선행: F3 탭별 퇴장과 기존 인증 상태 변경 연동.
- 인증 담당자 작업: 같은 브라우저의 같은 계정 탭에 로그아웃 상태 전파. 다른 기기의 인증 상태는 유지.
- B7 이벤트와 종료 사유를 함께 적용한다. 실제 로그아웃 API·탭 간 동기화 통합 검증은 인증 담당자 연동 후 수행한다.
- 실제 상위 이슈 번호·담당자·예상 소요·관련 PR은 등록 시 연결한다.

## 검증 계획

- Hook: 인증 제거/만료 알림 시 참여·메시지·전송 가능 상태 정리.
- 연결: CHAT_LOGGED_OUT 수신 시 전송·재연결·늦은 메시지 차단, 기존 토큰 갱신·복구 회귀 검증.
- 인증 모듈 연동 후: 같은 브라우저 두 탭 종료·다른 기기 유지 공동 검증.
